# Бот для записи на бьюти-услуги

Telegram-бот для одного мастера / одной услуги: запись клиентов, напоминания,
база клиентов, управление расписанием — всё через Telegram.

## Что умеет

**Клиенты:**
- Записаться на услугу (выбор даты и времени из свободных слотов)
- Посмотреть и отменить свои записи
- Получить автонапоминание за 24 часа и за 2 часа до визита

**Админ (ты):**
- `/admin` — открыть админ-меню
- Посмотреть записи на сегодня или на любую дату
- Посмотреть базу клиентов (с историей визитов)
- Отметить любой день как выходной (слоты в этот день не показываются)
- Отменить любую запись
- Сделать рассылку всем клиентам сразу

## Установка

1. Установи Python 3.10+
2. Создай бота через [@BotFather](https://t.me/BotFather) — получишь `BOT_TOKEN`
3. Узнай свой Telegram ID через [@userinfobot](https://t.me/userinfobot) — это `ADMIN_ID`
4. Скопируй `.env.example` в `.env` и впиши туда токен и свой ID:
   ```
   cp .env.example .env
   ```
5. Установи зависимости:
   ```
   pip install -r requirements.txt
   ```
6. Запусти бота:
   ```
   python main.py
   ```

## Настройка под себя

Открой `config.py` и поменяй:
- `SERVICE_NAME` — название твоей услуги
- `SERVICE_DURATION_MIN` / `SLOT_STEP_MIN` — длительность услуги и шаг между слотами
- `WORK_START_HOUR` / `WORK_END_HOUR` — рабочие часы
- `WORK_DAYS` — рабочие дни недели (0 = понедельник ... 6 = воскресенье)
- `DAYS_AHEAD_FOR_BOOKING` — на сколько дней вперёд можно записаться

Текст с ценой услуги — в `main.py`, функция `service_info`.

## Как выложить бота, чтобы он работал 24/7

Локально бот работает, только пока запущен на твоём компьютере. Чтобы он был
онлайн постоянно, задеплой его на хостинг, например:
- **Railway.app** или **Render.com** — есть бесплатные тарифы, деплой из GitHub за 10 минут
- Обычный VPS (от ~150₽/мес) + `screen`/`systemd`, чтобы процесс не падал

## Если продаёшь этот бот как продукт другим мастерам

Для каждого нового клиента нужен свой `BOT_TOKEN` (свой бот в Telegram) и своя
база данных (`DB_PATH` в `config.py`) — то есть отдельный запущенный процесс
на каждого мастера. Это самый простой вариант "одна инсталляция — один клиент".
Если понадобится сделать одного бота сразу на много мастеров (мультитенантность)
и оплату прямо в боте — это следующий уровень сложности, могу помочь и с этим.

## Оплата (следующий шаг)

Сейчас оплата не подключена — клиент просто записывается. Когда будешь готова,
можно добавить приём предоплаты прямо в боте через Telegram Payments
(ЮKassa, CloudPayments, Тинькофф и др. — все поддерживаются).
